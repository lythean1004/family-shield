Dependabot 알림을 켜자 web/ 에서 열린 알림 12건이 나왔다(높음 1, 중간 10, 낮음 1). 스킬·코어(서버)에는 없다.

|---|---|---|---|---|

| react-router 6.30.6 | 7.18.0 | **배포** | ① 백슬래시로 시작하는 주소를 `<Link>`·`navigate`에 넘기면 외부로 이동: 우리 코드는 모든 이동 대상이 `/`로 시작하는 고정 경로이거나 `/family/req/{id}` 꼴이라 해당 없음. ② SSR 복원 취약점: 서버 렌더링을 쓰지 않아 해당 없음 | 지금 악용 경로 없음 |

## 결정 (제안)

- **12/9 사용성 시험이 끝날 때까지 올리지 않는다.** 고친 버전은 모두 큰 버전 변경(vite 5→6, react-router 6→7, PWA 플러그인 동반 변경)이라 시험 직전에 화면·빌드가 깨질 위험이 더 크다.
- 그동안: 개발 서버는 이 PC 안(localhost)에서만 켜고, 새 코드에서 사용자 입력을 `navigate`·`<Link>` 대상으로 넘기지 않는다.
- **12/10~12/11 또는 12월 운영 기간에** vite 6·vite-plugin-pwa 최신·react-router 7로 올리고, 웹 시험 전체·빌드·미리보기 확인 뒤 배포한다.
- 알림은 닫지(dismiss) 않고 열어 둔다(올릴 때 확인용).
