# 인공지능기본법 제31조(투명성) 대조표 (결정 7A, 2026-11-28)

상태: **운영자 작성 자료, 법률 전문가 검토 전.** 법적 판단이 아니라 “조문이 요구하는 표시가 화면에 있는가”를 대조한 것이다.

## 원문 확인

- 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 [시행 2026. 7. 21.] [법률 제21311호, 2026. 1. 20., 일부개정] 제2조·제31조·제43조. 국가법령정보센터(law.go.kr)에서 2026-11-28 확인.
- 같은 법 시행령 [시행 2026. 8. 20.] [대통령령 제36580호] 제23조(인공지능 투명성 확보 의무). 같은 날 확인.
- 확인하지 못한 것: 과기정통부 고시·안내서(투명성 표시 세부, 적용 예외 고시), 과태료 계도기간 운영 여부. 확인 전에는 **유예가 없다고 보고** 대응한다.

## 요구 사항 요약 (원문 요지)

| 조항 | 요구 | 가족방패 해당 여부 |
|---|---|---|
| 법 31조① | 고영향·생성형 AI를 이용한 서비스는 AI 기반으로 운용된다는 사실을 이용자에게 **사전에 고지**. 위반 시 3천만원 이하 과태료(법 43조①1) | **해당**: 설명 문장을 생성형 AI가 만든다. 위험 단계는 규칙 코드가 정하므로 고영향(채용·대출 심사 등 열거 영역)에는 해당하지 않는다고 본다(전문가 확인 필요) |
| 법 31조② | 생성형 AI 결과물에 AI가 생성했다는 사실을 **표시** | **해당**: AI 설명 문장 |
| 법 31조③ | 실제와 구분하기 어려운 가상의 음향·이미지·영상은 명확히 인식할 수 있게 고지·표시 | 해당 없음으로 봄: 음성 읽기는 브라우저 기본 음성으로 화면 글을 읽는 것이고 사람 목소리를 흉내 내지 않는다 |
| 시행령 23조① | 사전 고지 방법: 이용약관 등에 기재 / 이용자 화면에 표시 / 장소 게시 등 **중 하나** | — |
| 시행령 23조② | 표시 방법: 사람이 인식할 수 있는 방법 또는 기계 판독(이 경우 1회 이상 안내 문구) | — |
| 시행령 23조④ | AI 활용 사실이 명백한 경우 등은 일부 적용하지 않을 수 있음 | 기대지 않는다(보수적으로 모두 표시) |

## 남은 확인 (전문가 검토 때 물을 것)

1. 규칙이 위험 단계를 정하는 구조에서 고영향 AI(법 2조4호)에 해당하지 않는다고 봐도 되는지.
2. 시험 운영(비영리, 1인)도 ‘인공지능이용사업자’(법 2조7호나목)로 보는지. 지금은 해당한다고 보고 대응했다.
3. 과기정통부 고시의 표시 세부 요건과 계도기간 여부.
