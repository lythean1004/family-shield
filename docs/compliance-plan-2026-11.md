## 2. 순서대로 할 일

### 1단계. 카카오 경로 즉시 보호 (11/28~11/29)

- **1-1. 임시 조치 — 하지 않기로 함(D59).** 바로 2단계를 배포한다. 원래 안: 2단계가 배포되기 전까지 카카오 경로를 규칙만 판정으로 돌린다. 설정값 하나로 켜고 끄게 만든다(`KAKAO_AI_ENABLED`).
  - 장점: 동의 없는 국외 이전이 바로 멈춘다.
  - 단점: 그동안 카카오 놓침률이 v16 기준 22%에서 67%로 올라간다.
  - 시험 참여자를 아직 받지 않았다면 영향은 운영자 시험뿐이다.
- 1-2. 카카오에서 지금까지 AI로 간 문장은 운영자 시험용 합성 문자였는지 기록으로 확인한다. 우리 서버에는 원문이 없으니 운영자 기억과 채널 친구 수로 확인한다.

### 2단계. 카카오 해외 AI 동의 받기 — 배포·운영 확인 완료(0cedf20)

- 처음 문자를 보내면 **규칙 판정 결과**와 함께 동의 안내 카드를 한 번 보여 준다.
  - 버튼: [AI로 더 자세히 보기 동의] [규칙만 쓰기] [자세히 보기(웹 처리방침)]
- 동의 전과 거절 후에는 계속 규칙만 판정한다. 거절해도 판별(기본 기능)은 막지 않는다(멘토 Q4).
- 동의를 끄는 방법: 채팅에 “AI 끄기”를 입력하거나 하단 메뉴 버튼을 누른다. 다시 켤 수도 있다.
- 저장 방식: **A안으로 결정(D59).**
  - **A안(추천):** 카카오 사용자 키의 비밀키 해시값, 동의 여부, 문구 버전, 시각만 DB에 둔다. 철회하면 갱신하고, 종료 시 파기한다.
  - B안: 저장하지 않고 문자마다 동의를 묻는다. 어르신이 매번 눌러야 해서 사용성이 나쁘다.
- 동의 안내 카드 문구에는 국외 이전 5요소의 요약과 웹 전문 링크를 넣는다(3단계 문구와 같은 버전).

### 3단계. 동의 문구 확정본(v5) 만들기 — 완료·배포(db5d709)

웹 동의 화면과 카카오 카드에 같은 내용을 쓴다. 해외 AI 항목에는 아래를 **빠짐없이** 적는다.

| 고지 요소 | 적을 내용(보수적 가정) |
|---|---|
| 이전 항목 | 가린 문장(전화번호·계좌·카드·주민번호·이메일·링크 주소·가족 이름을 가린 뒤). 가린 뒤에도 이름·주소 등이 남을 수 있음 |
| 이전 국가 | 미국 등 AI 제공사가 시설을 둔 국가(정확한 국가는 확인 중) |
| 시기·방법 | 문자를 보낼 때마다 암호화된 통신으로 전송 |
| 받는 자 | 모두의 AI 실험실 중계 서버 → Alrouter(아토리서치(주)) → Google(카카오)·Anthropic(웹). 각 연락처 |
| 목적·보유 기간 | 사기 신호 찾기와 설명 문장 만들기. 실험실 중계 7일. 제공사는 확인 중이며 최대 2년일 수 있음. 학습 이용 여부는 확인 중 |
| 거부 방법과 불이익 | 동의하지 않아도 판별은 됨. 대신 규칙만 판정해 놓치는 문자가 늘 수 있음 |

- 이해 확인 질문(맞음/틀림)을 해외 AI 항목에도 둔다(멘토 Q5).
- 문구 버전을 올리고(`CONSENT_VERSION`), 기존 시연 계정은 새 동의를 다시 거치게 한다.

### 4단계. 처리방침·약관 게시 — 배포 완료(f215b1d). 운영자 연락처만 남음

- 웹에 `/privacy`(처리방침)와 `/terms`(약관) 화면을 만든다.
- 링크를 둘 곳:
  - 웹 첫 화면 아래
  - 동의 화면
  - 카카오 동의 카드
  - 카카오 채널 프로필(운영자 작업)
- 처리방침에 1단계 가정과 3단계 표를 그대로 넣는다. 확인 안 된 칸은 비워 두지 않고 “확인 중(가장 넓게 가정)”으로 적는다.
- 운영자 이름과 연락 창구는 게시할 때만 넣는다(저장소에는 넣지 않음). 개인정보 보호책임자는 운영자 본인이다(멘토 Q13).
- 상단에 “시험 운영용, 전문가 검토 전” 표시를 둔다. ‘검수 완료’라고 쓰지 않는다.
- 약관은 포괄 면책 없이 서비스 역할, 놓침·오경보 가능성, 공식 경로 확인, 오류 신고, 종료 조건을 적는다(멘토 Q9).
- AI 이용 사실과 결과의 한계를 처리방침과 결과 화면에 밝힌다. 인공지능기본법 제31조는 원문을 확인한 뒤 맞춘다(P6).

### 5단계. 운영 기간 안내 — 웹 배포(74f1c04), 카카오 문안은 [notice-service-period.md](notice-service-period.md)(운영자 게시)

- 11/27 안내를 게시하지 않았다면 12/1에 1차 안내를 올린다.
  - 위치: 웹 배너, 카카오 채널 소식, 동의 화면
  - 내용: 12월 말까지 운영, 서버를 멈추는 날은 따로 알림, 종료 뒤 파기 범위(계정·동의 기록·카카오 동의 기록·판별 기록·DB 백업), 남기는 것(개인 식별 불가 통계·코드·문서)
- 종료일이 정해지면 D-14·D-1 안내 후 [종료 계획](shutdown-plan.md)대로 파기하고 기록을 남긴다.
- 사무국에 12/11 이후 VM·AI 중계 서버 사용 가능 기간을 묻는다. 안 되면 그날을 종료일로 알린다.
