# 문자 v3 개발과 독립 v4 검증

2026-11-27 운영자가 v3를 개발 자료로 전환하고 별도 작성자가 새 v4를 만드는 방식을 승인했다. 위험 놓침률과 위험 오경보율의 목표는 각각 10% 미만이다. 기준 코드는 `c50377d`다. 같은 커밋이 v3를 처음 보았을 때의 [독립 평가 결과](improve-sub10-2026-11.md#고정-후보의-독립-평가-결과)는 그대로 보존한다.

## 개발과 채점 기준

- v3에서 기준판의 놓침 36/53건과 위험 오경보 0/67건을 재현했다. 가족·지인 13건, 기관 7건, 기타 수법 10건, 경계 사례 6건을 놓쳤다. 이후의 v3 측정값은 개발 성능이다.
- v3의 원문과 사례별 분석은 로컬에서만 사용한다. v2와 기존 회귀 세트 230건도 사례별로 대조한다. 새 위험 오경보 또는 판정 하락이 생긴 후보는 적용 전에 수정하거나 폐기한다.
- 별도 작성자는 개발 코드·기존 평가 문장·판정 결과를 열람하지 않고, 한국어 합성 v4 문장과 정답을 작성한다. 합성 자료에는 실제 연락처와 작동하는 의심 주소를 쓰지 않는다. 실제 가족이 받은 문자의 운영 성능은 별도 측정이 필요하다.
- 독립 v4의 분모와 판정 경로는 이전 독립 평가와 같다. 개발 v2·v3에서 두 비율이 모두 10% 미만이고 회귀 검사를 통과한 코드 커밋을 고정한 뒤, 로컬 [집계기](../eval/score-aggregate.mjs)로 v4를 한 번 채점한다. 사례나 예측 목록은 공개하지 않는다. 두 오류율의 분모는 각각 `gold.level_rule`이 위험인 건수와 그 밖의 건수다.
