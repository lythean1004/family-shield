# 카카오 챗봇 관리자센터(오픈빌더) 연결

스킬 서버는 `https://familyshield.kr/api/kakao-skill`에서 동작한다. 아래는 사람이 챗봇 관리자센터에서 할 일이다. 메뉴 이름은 카카오비즈니스 가이드 「스킬 만들기」「블록에 스킬 적용하기」(2026-10-28 확인)와 10-21 직접 시험(`docs/kakao-bot-test-guide.md` 파트 B) 기준이다.

## 들어가는 곳

1. https://business.kakao.com 로그인 → 위 메뉴 **챗봇** (또는 바로 https://chatbot.kakao.com)
2. 10-21에 만든 봇을 클릭해서 연다.
3. 이제 **왼쪽 세로 메뉴**를 쓴다: `시나리오`, `엔티티`, `스킬`, `배포`, `봇테스트` 등이 있다.

## 1단계. 스킬 만들기 (왼쪽 메뉴 `스킬`)

1. 왼쪽 **스킬** 클릭 → 스킬 목록 화면. 10-21에 만든 `echo-test`가 있으면 그 줄을 눌러 고쳐도 된다.
2. 오른쪽 위 **생성** 클릭.
3. 칸을 채운다.

| 화면의 칸 | 넣을 값 |
|---|---|
| 스킬명 * | `가족방패 판별` |
| 설명 | 비워도 됨 |
| URL * | `https://familyshield.kr/api/kakao-skill` |
| Test URL | 비워도 됨 |
| 헤더값 입력 | 키 `x-skill-token`, 값 = 아래 토큰 |
| 테스트 헤더값 입력 | 위와 똑같이 한 번 더 |

**토큰 복사:** PC PowerShell에서 아래를 실행하면 토큰이 클립보드에 들어간다. 헤더값 칸에서 `Ctrl+V`.

```powershell
cd "D:\Claude Code\gongmojeon\family-shield"
powershell -ExecutionPolicy Bypass -File deploy\copy-skill-token.ps1
```

4. 같은 화면 아래 **스킬 테스트** 영역에서 **스킬 서버로 전송** 클릭.
   - 성공: **응답 미리보기**에 말풍선이 나온다. 발화가 비어 있으면 "판별할 문자 내용을 붙여 넣어 주세요."가 정상이다.
   - 실패: **응답 결과 로그**에 원인이 나온다. `403`이면 헤더값이 틀린 것(앞뒤 공백 확인).
5. **저장**.

## 2단계. 폴백 블록에 스킬 붙이기 (왼쪽 메뉴 `시나리오`)

부모님이 아무 문장이나 붙여 넣으므로, 봇이 모르는 말을 받는 **폴백 블록**이 입구다.

1. 왼쪽 **시나리오** → 기본 시나리오 안의 **폴백 블록** 클릭.
2. 블록 위쪽 **파라미터 설정**을 펼친다 → **스킬 선택**에서 `가족방패 판별` 선택(버전은 자동으로 최신).
3. 아래 **봇 응답**에서 응답 형식 추가 → **스킬데이터 사용** 선택.
4. 원래 있던 텍스트 응답은 지운다. 남기면 두 번 답한다.
   - 10-21 요령: 응답이 0개면 저장이 안 되므로 **스킬데이터 먼저 추가 → 기존 텍스트 삭제 → 저장** 순서로.
5. 오른쪽 위 **저장**.

## 3단계. 버튼 문구용 블록 (권장)

스킬 답의 "처음으로", "이미 당했어요" 버튼은 그 글자를 그대로 보낸다. 블록이 없으면 폴백(=판별)으로 가서 엉뚱한 판정이 나온다.

1. **시나리오** → **+ 블록 추가**.
2. 블록 `처음으로`: 사용자 발화 `처음으로`, 봇 응답은 웰컴 블록과 같은 문구.
3. 블록 `이미 당했어요`: 사용자 발화 `이미 당했어요`, 텍스트 응답:

```
지금 바로 112에 전화해 주세요.
돈을 보냈다면 은행에도 바로 알려야 합니다.
이 휴대폰 말고 다른 전화로 거는 것이 안전합니다.
```

번호는 112만 넣는다. 다른 기관 번호는 근거 카드 확인 전이다.

## 4단계. 배포 (왼쪽 메뉴 `배포`)

1. 왼쪽 **배포** → **배포**. 중간에 멈출 수 없고 최대 30분. 봇 상태가 **실행**이면 끝.
2. 배포 전에도 왼쪽 **봇테스트** 창으로 시험할 수 있다.

## 5단계. 시험

채널 채팅방 또는 **봇테스트** 창에 보낸다.

```
엄마 나 폰 고장났어. 이 번호로 문자해. 급하게 50만원만 보내줘
```

기대: `[⚡ 주의]` 또는 `[⚠️ 위험]`, 한계 문구, 버튼 3개(이미 당했어요 · 자세히 보기 · 처음으로).

서버 확인: `ssh fs-ncp "sudo journalctl -u family-shield-skill -n 20 --no-pager"` 에 `POST /api/kakao-skill 200` 줄이 있으면 카카오가 우리 서버를 부른 것이다.

## 문제가 생기면

| 증상 | 원인과 조치 |
|---|---|
| 스킬 테스트 403 | 헤더 키가 `x-skill-token`이 아니거나 값이 다름. 토큰 다시 복사 |
| "잘 모르겠어요"만 나옴 | 폴백의 기존 텍스트 응답을 안 지웠거나 배포 안 함 |
| 응답 시간 초과 | 카카오 제한 5초 고정. 로그의 ms 확인 |
| 휴대폰에서만 안 됨 | 배포 미완료(봇 상태 `실행` 확인) |
