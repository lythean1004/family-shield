# AI 설명 검토 표본 · 2026-11-27

합성 평가 실행기에 `--save-explanations`와 `--out`을 같이 주면 첫 실행의 **검증을 통과한 설명**이 해당 사례의 결과에 들어간다. 기본 실행은 기존 결과 형식을 유지한다. 저장 대상은 저장소의 개발·평가·보강 세트와 11월 보류 세트 1·2판이다. 경로·실제 파일 위치와 내용의 SHA-256을 확인하고 줄 끝 차이는 허용한다. 사례나 정답이 바뀌면 합성 자료임을 다시 확인하고 승인 판본을 갱신해야 한다. [승인 목록](../eval/synthetic-review.mjs)

보류 세트 2판에서는 법원 사칭 신고(HO-B-02)에 구체적인 행동 요구가 기록되지 않아 운영자 결정으로 사람 기대 단계를 ‘위험’에서 ‘주의’로 바꿨다. 두 판본의 본문·규칙 기대·나머지 정답은 동일하다. [1판](../eval/holdout-2026-11.jsonl) · [2판](../eval/holdout-2026-11-v2.jsonl)

`review-sample.mjs`는 실행 결과의 승인 판본과 사례 ID를 확인하고 설명이 있는 서로 다른 사례를 **예측 단계별**로 추출한다. 기본 30건, 같은 시드와 결과에는 같은 표본이 나온다. 한 단계가 부족하면 다른 단계의 사례로 채우고, 전체가 부족하면 가능한 수만 쓴다. AI 미사용·건강정보 제외·검증 후 빈 설명 행은 표본에서 빠진다. 확인 필요 단계의 설명이 표본에 들어가도 채널이 그 문장을 화면에 표시했다는 뜻은 아니다. 현재 카카오 확인 필요 답장은 고정 안내를 쓴다.

출력은 엑셀에서 읽을 수 있는 UTF-8 BOM CSV다. 각 행에서 맞춤법·사실 오류·안전처럼 읽힘·기타를 표시한다. `case_id`로 [합성 원본](../eval/holdout-2026-11.jsonl)과 대조할 수 있다. 이미 있는 CSV나 설명 결과 파일은 새 이름을 사용한다. [가짜 응답으로 만든 30건 예시](../eval/review/2026-11-27-holdout-mock-sample.csv)

## 사용법

아래는 로컬에서 기능을 확인한 방식이다. 모델 응답을 메모리에서 대신하는 시험 모듈과 예약 주소를 쓴다. `--out`에는 아직 없는 파일을 지정한다. 실험 데이터를 넣은 적이 없는 시험용 셸에서 실행한다.

```powershell
$env:AI_API_KEY='local-fixture'
$env:AI_BASE_URL='https://fixture.invalid/model'
node --import ./eval/test/fixtures/mock-explanation-model.mjs eval/run.mjs --model synthetic-mock --data eval/holdout-2026-11.jsonl --save-explanations --out D:/CodexTemp/family-shield/local-mock-new.jsonl
node eval/review-sample.mjs D:/CodexTemp/family-shield/local-mock-new.jsonl --count 30 --seed 2026-11
```

CSV는 기본적으로 `eval/review/<결과이름>-sample.csv`에 생긴다. `--out`으로 다른 이름을 지정할 수 있다. 운영자 승인 후 실제 평가의 설명을 수집할 때는 합성 자료 평가 실행기에만 같은 저장 옵션을 준다. 이번 CSV의 문장은 시험용 가짜 응답이므로 실제 AI 오탈자율이나 사실 오류율을 집계하는 자료로 쓸 수 없다.

## 검증 결과

- 40자보다 긴 설명은 문장 전체를 제외한다. 중간에서 잘려 뜻이 달라지는 일을 막는다. 내부 신호 이름·무이상을 단정하는 표현·보이지 않는 문자 등도 제외한다. 한글이 들어 있는 짧은 문장에서 QR·ATM 같은 영문 약어와 기본 문장부호는 허용한다. 개별 어휘의 맞춤법과 사실성은 사람이 판단한다.
- 설명을 모두 제외해도 유효한 위험 신호와 판정은 살아 있다. 카카오는 정해진 신호 요약을 표시한다. 주의·위험 웹 화면과 음성에는 같은 고정 문구가 들어간다. 1회용 토큰으로 불러온 기록도 설명이 비기 때문에, 안내는 “표시할 추가 설명이 없어요”라고 알려 주며 모델 호출의 성공 여부를 단정하지 않는다.
- 수정 전 필터·카카오 회귀 시험 3개와 웹 고정 문구 시험 1개가 실패했고 수정 후 통과했다. 합성 파일 바꿔치기·동명이지만 다른 경로·옵션 없는 결과·중복 사례·단계별 표본 부족·기존 CSV 보호를 로컬에서 확인했다. 제품 시험은 **코어 447/447, 스킬 94/94, 웹 174/174**이고 별도 평가 도구 시험은 **11/11**이다.

## 작업 기록에 옮길 세 줄

1. 승인된 합성 평가 판본에 한해 첫 실행에서 검증한 설명을 저장하는 선택 옵션을 추가했다.
2. 예측 단계별 복원 없는 추출과 검수 CSV를 구현하고 가짜 모델로 위험·주의·확인 필요 각 10건을 확인했다.
3. 과도하게 긴 설명·단정 표현 등을 제외하고, 설명이 비었을 때 판정과 고정 안내가 유지되는지 카카오와 웹에서 확인했다.
