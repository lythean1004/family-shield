# 동의 화면 재설계안 (작업 ⑤) — 설계안, 운영자 승인 전

작성일: 2026-11-11 · 근거: 멘토 1차 답변 Q4·Q5(요약은 decisions D43), D26(동의 문구는 법률 검토 뒤 확정), D43(지금은 합성 문자 시나리오만)
상태: **운영자 승인(2026-11-11): 구조 확정, 화면은 ‘눌러서 펼쳐 보기 + 전체 동의/개별 동의’.** 문구는 초안이며 전문가 확인 전에는 “확정”이라고 하지 않는다. 실제 문자 처리는 운영 승인 서류 4가지를 갖춘 뒤.

## 1. 지금 구조와 문제

| 지금(`web/src/screens/SetupScreen.jsx`, `demo-2026-10-28-v2`) | 멘토 지적 |

| ② 가족에게 묻기: ①에 동의해야 가능 | 목적·수신자가 다르면 별도 선택 유지(지금 구조 유지) |

## 2. 새 구조 (화면 하나에 선택 하나, 기존 원칙 유지)

| 순서 | 항목(저장 이름) | 성격 | 거절하면 |
|---|---|---|---|
| 0 | 이용 안내(동의 아님) | 무엇을 하는지, 원문 미저장, 결과는 참고용, 처리방침 링크 | — |
| ① | **해외 AI 분석** (`overseas_ai`, 새 항목) | 국외 이전 동의 | **규칙만으로 판정**(AI 설명 없음). 판별 자체는 그대로 쓸 수 있다 |
| ② | **가족에게 결과 보내기** (`family_alert`) | 제3자 제공 동의. **받는 사람 이름·관계를 화면에 표시** | 가족 기능만 꺼짐. 판별은 그대로 |
| ③ | 가족에게 진짜인지 묻기 (`impersonation_check`) | 제3자 제공(사칭된 가족 본인) | 묻기 기능만 꺼짐 |
| ④ | 확인 기록 24시간 (`check_log`) | 선택 | 요청할 때마다 그 건만 처리 기록 동의(지금 D38 방식 유지) |

- 순서를 ①국외 이전 → ②가족 제공으로 바꿔, 가족 제공 동의 안에 국외 이전이 섞이지 않게 한다.
- **거절해도 판별(기본 기능)은 막지 않는다**(멘토 Q4, 제22조).
- 카카오 입구: 카카오 사용자는 웹 계정과 연결되어 있지 않다. **[결정 필요]** 실제 문자를 받기 시작할 때 카카오 첫 사용 안내(웰컴 블록)에서 ① 해외 AI 분석 여부를 버튼으로 받거나, 받기 전에는 카카오에서 규칙만 판정. 지금(합성 시나리오)은 영향 없음.

## 2-1. 화면 방식 (운영자 결정)
- 한 화면에 항목 목록. 각 항목은 **제목 + 한 줄 요약 + [자세히]** 버튼. 누르면 자세한 내용이 펼쳐진다(음성 읽기 가능).
- 각 항목 옆에 **개별 선택**(허락/허락 안 함). 위에 **[모두 허락]** 버튼 하나. 미리 체크해 두지 않는다(모두 ‘선택 안 함’에서 시작).
- 해외 AI 분석과 가족 제공은 **서로 다른 항목**으로 보이므로 전체 동의를 눌러도 항목별 내용·선택이 구분된다. [모두 허락] 뒤에도 개별로 끌 수 있다.
- ③ 가족에게 묻기는 ② 가족에게 결과 보내기를 허락해야 켤 수 있다(지금 규칙 유지).
- [저장] 뒤 ②를 허락했다면 이해 확인 질문 하나.

## 3. 화면 문구 초안 (전문가 확인 전, 부모님 글자 150%)

**① 해외 AI 분석**
> 문자를 더 정확하게 살펴보려고, 번호·계좌 같은 정보를 가린 문장을 해외 AI에 보내 분석해요.
> - 보내는 것: 가린 문장(원문·번호·계좌는 보내지 않아요)
> - 거쳐 가는 곳: 모두의 AI 실험실 중계 서버(국내) [운영사 법인명: 답변 후 기입]
> - 받는 곳: Anthropic, PBC(미국, Claude), Google Cloud Korea LLC를 통한 Google(Gemini, 처리 국가는 Google 시설이 있는 나라)
> - 보관: Anthropic은 30일 안에 삭제(정책 위반으로 분류되면 최대 2년), Google은 정책 위반 확인을 위해 제한된 기간 보관
> - 학습: 두 회사 모두 유료 API 내용은 학습에 쓰지 않는다고 밝히고 있어요 [운영사가 유료로 쓰는지 확인 후 확정]
> - 언제 보내나: 문자를 확인할 때마다, 인터넷으로 바로
> - 거절해도 괜찮아요. 거절하면 AI 없이 정해진 규칙으로만 알려 드려요.
> [해외 AI 분석 사용] [사용 안 함]

**② 가족에게 결과 보내기**
> 내가 “가족에게 물어보기”를 누를 때, 아래 가족이 위험 단계와 정해진 요약을 볼 수 있어요.
> - 받는 사람: **김지은(딸)**, **김민수(아들)** ← 실제 연결된 가족 표시
> - 보내는 것: 위험 단계, 정해진 요약 문장, 사칭된 관계, (입력했다면) 번호 끝 4자리
> - 보내지 않는 것: 문자 원문, 전체 번호
> - 언제든 [내 설정]에서 끌 수 있어요.
> [보내기 허락] [허락 안 함]

**이해 확인(②·③ 뒤 한 번, 고령자 동의 유효성)**
> 방금 허락한 내용이 맞는지 확인할게요. 위험한 문자를 받으면 누가 결과를 보나요?
> [김지은(딸), 김민수(아들)] [아무도 안 봐요] [잘 모르겠어요]
> - 맞게 고르면 다음으로. “잘 모르겠어요”나 다르게 고르면 설명을 다시 보여 주고(음성 읽기 버튼 포함), 그래도 어려우면 **보호자 도움 없이 다시 하도록** 안내.
> - 이 확인 결과(맞음/다시 봄)만 동의 기록에 함께 남긴다. 답 자체는 개인정보가 아니다.

**④ 확인 기록**(지금 문구 유지, 백업 표현만 명확히)
> 위험 단계와 신호 같은 확인 기록을 24시간 보관해요. 문자 원문은 저장하지 않아요. 삭제는 10분마다 하고, 비상용 백업에는 삭제 뒤에도 최대 7일 남을 수 있어요.
