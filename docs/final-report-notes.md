# 결과보고서에 넣을 것 (메모, 2026-11-28 시작)

결과보고서(12/11) 작성 때 빠뜨리지 않도록 모은다. 숫자는 원 문서를 따르고, 피해 감소 효과는 주장하지 않는다.

## 1. 평가 숫자와 측정 조건 (D63)

- 처음 보는 합성 문자 120건(v16, [평가 문서](eval-v16-2026-11.md)): 프롬프트 v4 **놓침률 22.4% (33/147)**, 오경보율 3.3% (7/213), 3회 반복. 목표(5% 이하)에는 못 미친다.
- 측정 조건을 함께 적는다: 이날 중계 서버가 느려 **시간 초과가 20.0%**였다(오전 측정은 1~2%). 시간 초과 때는 규칙만으로 판정하므로 놓침이 늘어난다. 재측정은 하지 않았다(결정 5B).
- 규칙만(AI 없음): 위험 49건 중 33건 놓침. 동의하지 않은 사용자는 이 수준이다(D59).
