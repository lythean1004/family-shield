# 카카오 채널 하단 메뉴(CTA) 설정 가이드

작성일: 2026-11-26 · 계기: 멘토링(2026-11-26) “‘의심’ 뒤 행동을 버튼으로 누르게 하기보다 채널 하단에 늘 보이게”
대상: 운영자가 챗봇 관리자센터에서 직접 하는 설정. 서버 코드 변경 없음.

## 0. 먼저 알아 둘 것

- 채팅방 하단 메뉴는 두 곳에서 만들 수 있지만 **가족방패는 챗봇을 쓰므로 ‘봇 리스트 메뉴’(챗봇 관리자센터)만 쓴다.**
  - 채널 관리자센터의 ‘채팅방 메뉴’(커스텀·리스트 메뉴)와 ‘자동응답’은 **챗봇과 동시에 쓸 수 없다.** 켜져 있으면 끈다.
- 봇 리스트 메뉴 버튼은 **블록 연결** 또는 **메시지 전송** 두 가지뿐이다(주소 바로 열기 없음). 버튼 이름은 **최대 14자**.
- 수정한 뒤 **배포**해야 운영 채널에 보이고, 보이기까지 시간이 걸릴 수 있다.
- 가이드 문서에 사업자 인증이 필요하다는 내용은 없었다(상담 연결 버튼만 별도 조건). 실제 화면에서 확인한다.
- 원칙 유지: 가족방패는 먼저 메시지를 보내지 않는다. 메뉴는 부모님이 누를 때만 동작한다. 웹 주소 버튼도 부모님이 누를 때만 열린다(D25).

출처: [카카오비즈니스 가이드 · 시나리오(봇 리스트 메뉴)](https://kakaobusiness.gitbook.io/main/tool/chatbot/main_notions/scenario), [채팅방 메뉴(채널 관리자센터)](https://kakaobusiness.gitbook.io/main/partner/smb/channel/step2/chat2) — 2026-11-26 확인. 화면 이름은 바뀔 수 있다.

## 1단계. 채널 관리자센터 메뉴 끄기

1. 카카오톡 채널 관리자센터 → 가족방패 채널 → **비즈니스 도구 → 채팅방 메뉴**.
2. 커스텀 메뉴·리스트 메뉴가 **OFF**인지 확인. 자동응답도 OFF.

## 2단계. 메뉴가 연결될 블록 만들기 (챗봇 관리자센터 → 시나리오 → + 블록 추가)

블록이 없으면 버튼 글자가 폴백(=판별)으로 가서 엉뚱한 판정이 나온다. 이미 있는 `이미 당했어요`·`처음으로` 블록은 그대로 쓴다(`docs/kakao-openbuilder-setup.md` 3단계).

| 블록 이름 | 사용자 발화 | 봇 응답(텍스트) | 버튼(선택) |
|---|---|---|---|
| `사용법` | 사용법 | 의심 문자를 길게 눌러 복사한 뒤 여기에 붙여 넣어 보내 주세요.<br>카카오톡 메시지는 길게 눌러 [전달]을 누르고 ‘가족방패’를 고르면 돼요.<br>가족방패는 링크를 열지 않고, 문자 원문을 저장하지 않아요. | — |
| `공식 번호` | 공식 번호 | 경찰은 112예요.<br>다른 기관 번호는 아래 [공식 번호 보기]에서 출처와 함께 확인하세요.<br>문자 속 번호로는 전화하지 마세요. | 웹링크 `공식 번호 보기` → `https://familyshield.kr/contacts` |
| `이미 당했어요` | 이미 당했어요 | (기존 블록 그대로: 112, 은행, 다른 전화로) | 웹링크 `단계별로 보기` → `https://familyshield.kr/help` (선택) |
| `오늘의 퀴즈` | 오늘의 퀴즈 | 진짜 같은 사기 문자를 연습해 볼까요? 연습 기록은 실제 알림에 쓰지 않아요. | 웹링크 `퀴즈 풀기` → `https://familyshield.kr/quiz` |

- 번호는 근거 카드에 있는 것만 쓴다(112는 확인됨). 금융감독원·대검찰청 번호는 웹 [공식 번호 보기]에 출처와 함께 있으니 챗봇 글에는 직접 적지 않는다.

## 3단계. 봇 리스트 메뉴 켜기

1. 챗봇 관리자센터 → **시나리오** → 시나리오 이름 옆 **톱니바퀴(시나리오 설정)**.
2. **봇 리스트 메뉴** 사용 **ON**.
3. **버튼 추가** → 버튼 설정에서 이름과 **블록 연결**을 고른다. 추천 순서(부모님이 가장 급한 것부터):

| 순서 | 버튼 이름(14자 이내) | 연결 |
|---|---|---|
| 1 | 이미 당했어요 | 블록 `이미 당했어요` |
| 2 | 공식 번호 | 블록 `공식 번호` |
| 3 | 사용법 | 블록 `사용법` |
| 4 | 오늘의 퀴즈 | 블록 `오늘의 퀴즈` |

## 4단계. 배포와 시험

1. 왼쪽 **배포** → **배포**(최대 30분). 봇 상태가 **실행**이면 끝.
2. 휴대폰 채널 대화방 아래 메뉴에서 네 버튼을 하나씩 눌러 본다.
   - 기대: 각 블록의 글이 나오고, 판별(위험/주의/확인 필요) 답이 **나오지 않아야** 한다. 판별 답이 나오면 블록 발화가 버튼 이름과 다르거나 배포 전이다.
3. 의심 문자 하나를 붙여 넣어 판별이 그대로 되는지도 확인한다.

## 5. 함께 하면 좋은 것 (서버 변경, 별도 승인)

- 판정 답장 본문에 ‘지금 할 일’ 한 줄을 문장으로 넣기(예: 위험·주의일 때 “문자 속 번호 말고 112나 직접 찾은 공식 번호로 확인하세요.”). 하단 메뉴와 겹쳐 부모님이 버튼을 안 눌러도 할 일을 알 수 있다.
- 채널 홈 ‘소식(포스트)’에 시즌별 주의 안내 올리기(근거 카드의 공식 경고문만). 소식은 채널 홈에 게시되는 것이고 친구에게 메시지를 보내는 기능이 아니다. 메시지 발송은 하지 않는다.
