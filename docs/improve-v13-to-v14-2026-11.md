# 작성자 간 재현성과 v13 이후 코드 검증

독립 v13의 최초 성적은 규칙 기준 놓침 23/39(59.0%)·위험 오경보 0/81이었다. 합성 작성자가 따로 정한 기대 판정에 대해서는 23/38·1/82였다. [후보와 최초 측정 기록](improve-v12-to-v13-2026-11.md)

## 과거 코드의 작성자 간 전이

과거 고정 커밋 6개로 v9~v12 작성자 8명의 동일한 합성 480건을 총 2,880회 재판정했다. 원래 부모 입력 38건을 전달했고, 외부 AI·주소 평판·도메인 생성일 조회를 끈 로컬 제품 진입점을 사용했다. 각 판본의 최초 규칙·작성자 기대 놓침과 오경보 16개 분자가 기존 기록과 일치했다.

| 코드 구간 | 그 구간에 개발한 판본의 위험 회복 | 양쪽 시점에 아직 보지 않은 후속 판본의 위험 회복 |
|---|---|---|
| `b12a6fd` → `f6a1d01` | 이 네 판본 중 없음 | v9 1건, v10 1건, v11 3건, v12 2건 |
| `f6a1d01` → `86f1ac5` | v9 18건 | v10~v12 0건 |
| `86f1ac5` → `8dc8322` | v10 27건 | v11·v12 0건 |
| `8dc8322` → `ffec4bc` | v11 24건 | v12 1건 |
| `ffec4bc` → `77fce1b` | v12 14건 | 네 판본 모두 개발에 편입됨 |

첫 커밋과 마지막 커밋을 비교하면 위험 160건 중 놓침이 120건에서 27건으로 줄었다. 회복 93건 중 8건은 해당 판본을 처음 보기 전, 85건은 개발에 편입한 후 관측했다. 앞선 8건은 보호 앱 삭제 4건, 개인·제3자 계좌 납부 2건, 가족 사칭·새 연락처에서의 민감자료 요구 1건, 수사기관 명목의 현금 인계 1건이다. 규칙과 작성자 기대 모두에서 같은 여덟 건이 회복됐다. 두 기준의 위험 오경보는 전 구간 각각 1/320, 10/326이었다. 각 구간에는 여러 코드 변경이 포함됐다.

## 다음 평가판과 개발 자료

두 새 작성자가 코드와 이전 사례를 보지 않고 각각 60건을 작성했다. v13의 개발용 본문을 열기 전 v14 입력과 정답 120건을 고정했다. 과거 1,670건과 공백·유니코드를 정규화한 뒤 본문 전체가 같은 사례는 0건이었다.

| 자료 | SHA-256 | 규칙 위험 / 그 외 | 작성자 기대 위험 / 그 외 |
|---|---|---:|---:|
| v14 첫 작성자 | `3b197d473a26ddca4dde76a0609c804564a7dc1ebd6450d51d5b5f3921e465a0` | 18/42 | 17/43 |
| v14 둘째 작성자 | `b902f5fc5366d27ad95d03e0b9305a20a67fc8a304b91b520e2afad073e42ad3` | 23/37 | 24/36 |
| v14 전체 | `b3e6703bbef992e196e6404d1d14315e48b23a1b6197d765d2d13ac548831dea` | 41/79 | 41/79 |

v14에서 두 지표가 각각 10% 미만이려면 규칙 위험 놓침이 4건 이하, 위험 오경보가 7건 이하여야 한다. 형식은 수신 경위 설명 53건, 발췌 36건, 직접 문자 형식 31건이다. 위험 상황은 비작동 관찰 서술로 작성했다. 실제 사기 문자에 대한 놓침률은 이 실험으로 추정할 수 없다.

v13은 최초 점수를 보존한 뒤 첫 작성자의 60건을 개발에 사용한다. 첫 작성자의 기존 성적은 규칙 놓침 12/19·오경보 0/41이다. 둘째 작성자의 개별 본문과 예측은 새 후보를 고정할 때까지 개발에 사용하지 않는다. 명시적 역할과 행동을 읽는 후보의 개발 효과와, 아직 보지 않은 작성자에게서 얻는 효과를 따로 기록한다.
