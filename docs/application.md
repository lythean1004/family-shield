# 2. 프로젝트 내용 및 목표

## 2-1. 프로젝트 개요

<table>
<colgroup>
<col style="width: 25%" />
<col style="width: 74%" />
</colgroup>
<thead>
<tr>
<th><strong>프로젝트 한 줄 소개</strong></th>
<th>문자·메신저로 의심스러운 메시지를 받은 부모님이 그 순간 무엇을 해야
할지 모르는 문제를 AI로 돕습니다. 메시지를 붙여 넣으면 위험 신호를 쉬운
말로 짚어 주고 지금 할 행동을 안내하며, 위험이 크면 미리 연결한 가족에게
바로 알립니다.</th>
</tr>
<tr>
<th><strong>서비스 주요 내용</strong></th>
<th><p><strong>① 메시지 확인</strong> 부모님이 받은 문자·메신저 내용을
붙여 넣으면 기관·택배·가족 사칭, 링크·앱 설치 요구, 송금·개인정보 요구,
재촉 같은 위험 신호를 찾아 보여 줍니다.</p>
<p><strong>② 위험 단계와 쉬운 설명</strong> ‘위험 / 주의 / 확인 필요’
3단계와 그렇게 본 이유를 큰 글씨, 짧은 문장으로 보여 줍니다. ‘안전’
판정은 내지 않고, 신호가 없어도 공식 경로로 확인하도록 안내합니다.</p>
<p><strong>③ 지금 할 행동 안내</strong> 링크 누르지 않기, 답장·송금
멈추기, 공식 번호로 직접 확인하기 등을 버튼 하나로 따라 할 수 있게
안내합니다. 연락처와 절차는 공식 안내를 정리한 근거 카드에서만
가져옵니다.</p>
<p><strong>④ 가족 알림</strong> ‘위험’ 단계이면 부모님이 미리 동의해
연결한 가족에게 위험 단계와 요약을 바로 알립니다. 메시지 원문은 보내지
않습니다.</p>
<p><strong>⑤ 결과의 한계 표시</strong> 판별은 참고용이며 정상 메시지를
위험으로 보거나 위험을 놓칠 수 있다는 점을 화면에 함께
표시합니다.</p></th>
</tr>
<tr>
<th><strong>AI 활용방식</strong></th>
<th><p><strong>AI 역할</strong> 한국어 텍스트 생성 모델 1종(API, 별도
학습 없음)이 메시지에서 위험 신호를 뽑고 쉬운 설명 문장을 만듭니다.
출력은 신호 목록·근거 카드 ID·설명으로 나눈 정형 JSON으로 받습니다.</p>
<p><strong>판정은 규칙</strong> 위험 단계 결정과 가족 알림 여부는 미리
정한 규칙(코드)이 처리합니다. 프로그램이 출력 형식과 근거 ID를 검사하고,
오류·시간 초과 시 검토된 고정 안내로 전환합니다.</p>
<p><strong>데이터</strong> KISA 보호나라·금융당국의 공개 예방 안내 중
이용조건을 확인한 내용을 근거 카드로 정리하고, 위험·정상 메시지를 섞은
합성 평가셋을 직접 만들어 놓침과 오경보를 측정합니다.</p>
<p><strong>개인정보</strong> 전화번호·계좌번호 등은 모델 전송 전에
가리고, 메시지 원문은 저장하지 않습니다. 사용 모델, 캡처 이미지 인식,
알림 채널(문자·메신저 연동)은 검토 중입니다.</p></th>
</tr>
