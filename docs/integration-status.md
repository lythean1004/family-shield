13개 규칙을 행별로 비교했다. R1·R2·R3·R5·R8·R9·R12의 발동 조건과 단계는 일치했다. 운영자 확인 후 반영할 문서 차이는 다음 6개다. [PRD 규칙표](prd.md#9-7-판정-단계의-뜻과-규칙) · [규칙 엔진](../packages/core/src/rule-engine.js) · [결정 기록](decisions.md)

| 규칙 | PRD 표에 보충할 내용 | 현재 코드 근거 |
|---|---|---|
| R4 | 가족 사칭과 결합하는 통화 회피는 코드가 찾은 신호를 사용 | D46 |
| R6 | 모든 링크가 공식일 때는 링크만으로 기관 사칭 위험이 발동하지 않는다. 설치·개인정보·번호 유도는 여전히 위험이다. | D48 |
| R7 | 공식 링크 자체는 제외. 이때 돈·재촉·비밀은 코드 신호를 쓰고, 개인정보는 AI와의 합집합을 쓴다. | D47·D49 |
