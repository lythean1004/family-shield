## 1. 지금 무엇이 다른가 (코드 확인 결과)

카카오 답은 판정 직후 메모리에 있는 결과 전체로 만든다(`skill/src/handler.js` `buildReplyText`). [자세히 보기]는 DB `public.checks`에 **정해진 값만** 저장했다가 다시 읽어 웹 화면(`ResultView`)을 그린다(`skill/src/results.js`). 원문·AI 문장을 저장하지 않는 원칙 때문인데, 그 결과 아래가 달라진다.

| 상황 | 카카오 답 | 웹 [자세히 보기] | 문제 |
|---|---|---|---|
| AI 설명이 나온 경우 | AI 설명 + “위 설명은 AI가 만든 문장이에요” | 설명 없음 → “표시할 추가 설명이 없어요. 판정은 그대로예요.” | **설명이 사라지고**, AI 설명이 없었던 것처럼 보임 |
| 동의 전(규칙만) | “※ 지금은 규칙으로만 확인했어요 … [AI 분석 안내]” | “표시할 추가 설명이 없어요” | 왜 설명이 없는지 다름 |
| 거절·‘AI 끄기’ 뒤 | 규칙만 판정, 안내 줄 없음 | “표시할 추가 설명이 없어요” | 웹 직접 입력은 “해외 AI 분석을 허락하지 않아…”인데 카카오 경유는 아님 |
| 건강 표현으로 AI 안 보냄 | “건강 관련 내용이 있어 해외 AI로 보내지 않았어요.” | 저장 안 됨(`ai_skipped` 없음) → 일반 문구 | 안내 누락 |
| AI 시간 초과·검증 실패 | “감지된 신호: …” | 신호 목록 + “표시할 추가 설명이 없어요” | 뜻은 같고 문구만 다름(허용) |
| 위험 이유(R10~R19 코드 신호) | “위험 이유: …” 줄 | 신호 목록에 들어 있음 | 같은 내용, 표현만 다름(허용) |
| 확인 필요 · 단축 링크 · 공식 주소 · Google 경고 | 고정 문장 | 같은 고정 문장(core/fixed-text.js 공유) | 일치 |

그 밖에: 웹 직접 입력(`/api/analyze`)은 근거 카드를 쓰고 카카오는 `cards: []`로 부른다. 같은 문자라도 공식 번호 안내 등 근거 연결이 다를 수 있어 함께 확인한다.

## 3. 작업 순서 (A 기준)

1. **시험 먼저**: “같은 판정, 같은 안내” 표 시험을 만든다. 경우의 수(단계 3 × 동의 상태 4 × AI 결과 3 + 건강·단축·공식 주소·Google·R1 통화 중)마다 카카오 답과 웹 [자세히 보기] 화면에 **같은 고정 문장이 들어가는지** 비교. 지금 코드에서 실패하는 것을 먼저 확인한다.
2. 한 곳에서 문장 고르기: `packages/core`에 “결과 → 보여 줄 안내 목록” 함수를 두고 카카오·웹이 함께 쓴다(지금은 양쪽에 따로 있음).
3. DB: `checks`에 `ai_state` 한 칸 추가(이주 파일 + 서버 임시 DB 통합 시험). 저장 전 버전 결과(값 없음)는 지금 문구로 보여 준다(배포 직후 열린 링크 대비).
4. 웹 직접 입력·카카오의 근거 카드 차이 확인, 필요하면 맞춤.
5. 처리방침 1장 ‘판별 기록’에 “AI 사용 상태(동의 전·거절·건강정보 등)” 한 단어 추가(문장 저장 아님) → 버전 v3.
6. 배포: 스킬 → 이주 → 웹. 카카오에서 실제로 동의 전/동의/끄기 3상태로 같은 합성 문자를 보내 두 화면을 눈으로 비교(시연 코드 확인과 함께).

## 4. ‘AI 끄기’ 비슷한 말 인식

지금은 버튼 글과 **글자 하나까지 같을 때만** 명령으로 본다(`parseConsentCommand`). 그래서 “ai끄기”, “Ai 끄기”, “AI 끄기요”는 문자 판별로 넘어가 엉뚱한 결과(확인 필요 등)가 나온다.

- 고르는 법: 메시지 **전체가 짧은 명령 한 줄**일 때만 바꿔 읽는다(문자 속에 섞인 “AI 끄기”는 명령으로 보지 않음). 띄어쓰기·대소문자·전각 문자·끝의 “요/!/./~” 차이를 무시한다.
- 철회(끄기)는 넓게 받는다(동의만큼 쉬워야 함): `AI 끄기`, `ai끄기`, `AI 꺼줘`, `AI 꺼 주세요`, `AI 그만`, `AI 안 쓸래요`, `에이아이 끄기`, `인공지능 끄기`, `AI 분석 끄기`, `AI 동의 철회`, `동의 철회`.
- 동의는 **좁게** 받는다(분명한 뜻만): 버튼 문장의 띄어쓰기·대소문자·끝 문장부호 차이만. “동의”, “네” 같은 짧은 말은 동의로 보지 않는다.
- 안내·규칙만도 같은 정규화(`ai분석안내`, `규칙만쓸게요`).
- 시험 먼저: 위 목록 + 아닌 것(“AI 끄는 법 알려줘”는 안내로? → 안내 답으로, “엄마 AI 끄기 했어?” 같은 문장은 명령 아님) 표로.
- 카카오 챗봇 관리자에서 비슷한 말이 다른 블록으로 가지 않는지(폴백 → 스킬로 오는지) 확인.
