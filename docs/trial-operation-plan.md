## 1. 기본 가정 (가장 보수적으로)

- **사무국·Alrouter 답변이 오지 않는다고 본다.** 처리방침·동의 문구는 지금처럼 “확인 중·가장 넓게” 적은 채로 운영한다. 답이 오면 문구를 고치고 버전을 올려 다시 동의를 받는다.
- **12/11 이후 서버를 계속 쓸 수 있는지 모른다고 본다.** 그래서 시험은 **12/9까지 끝내고**, 참여자에게 “12월 말까지 예정이지만 더 일찍 멈출 수 있고, 멈추면 개인정보를 지운다”고 말한다.
- 실제 문자 처리는 서류 ①~④와 전문가 확인이 끝날 때까지 하지 않는다.

## 6. 직접 설명 대본 (운영자가 읽음, 약 3분)

> 안녕하세요. 저는 가족방패를 만든 ○○○입니다. 가족방패는 의심 문자를 받았을 때 혼자 판단하지 않도록 돕는 **시험 서비스**예요. 12월 말까지 운영할 예정이지만 더 일찍 멈출 수도 있고, 멈추면 계정과 기록을 모두 지워요.
>
> 오늘은 제가 드리는 **가짜 문자**로만 써 주세요. 실제로 받은 문자, 이름, 전화번호, 계좌번호는 넣지 말아 주세요.
>
> 카카오 채널은 사업자 인증을 하지 않은 일반 채널이라 ‘사업자 정보 미확인’이라고 보일 수 있어요. 제가 운영하는 채널이 맞습니다.
>
> 문자를 붙여 넣으면 먼저 정해진 규칙으로 확인해요. 원하시면 [AI 분석 안내]에서 동의할 수 있는데, 동의하시면 번호·계좌를 가린 문장이 **미국 등 해외 AI 회사**로 가요. 그 회사들이 얼마나 보관하는지는 아직 확인 중이라 가장 길게(최대 2년, 학습에 쓰일 수도 있다고) 잡아 안내하고 있어요. 동의하지 않아도 문자 확인은 돼요. 그만두고 싶으면 언제든 ‘AI 끄기’라고 보내시면 돼요.
>
> 결과는 참고용이에요. 정상 문자를 위험으로 보거나 위험한 문자를 놓칠 수 있어요. 확실하지 않으면 문자 속 번호 말고, 직접 찾은 공식 번호로 확인하세요.
>
> 오늘 하신 내용은 문자 원문 없이 어떤 버튼을 골랐는지만 제가 종이에 적어요. 이름이나 연락처는 적지 않아요. 중간에 그만두셔도 괜찮아요. 궁금한 점 있으세요?

- 설명 후 “AI 분석에 동의하면 문장이 어디로 가나요?”를 말로 물어 이해를 확인한다(웹 이해 확인과 같은 질문).
- 동의 여부는 참여자가 직접 누른다. 운영자나 보호자가 대신 누르지 않는다.

## 7. 카드와 질문

카드 본문은 `private/trial-cards-2026-11-28.md`(커밋 금지). 번호는 쓰이지 않는 형식, 링크는 예약 도메인만.

| 카드 | 유형 | 규칙만 결과 | 질문(정답) |
|---|---|---|---|
| A | 가족 사칭(SC1) | 위험 | “무슨 뜻인가요?”(사기일 수 있음) / “뭘 하시겠어요?”(원래 번호로 가족에게 전화, [가족에게 물어보기]) |
| B | 기관 + 전화 유도(SC2) | 위험 | “문자 속 번호로 전화하시겠어요?”(아니요, [공식 번호 보기]) |
| C | 이미 눌렀어요(SC3) | 주의 | “이미 눌렀다면 어디를 누르시겠어요?”([이미 눌렀거나 보냈어요]) |
| D | 약한 신호(SC4) | 확인 필요 | “‘확인 필요’는 안전하다는 뜻인가요?”(아니요) |
| E | 처음 보는 유형 | 주의 | 질문 없이 행동만 기록(가족 확인·공식 번호·보낸 사람에게 직접 확인) |

AI에 동의한 참여자는 설명 문장이 붙고 단계가 오를 수 있다. 동의 여부를 기록표에 적어 나눠 집계한다.

## 9. 측정 지표와 보고 (PRD 15-2)

| 지표 | 계산 | 목표 |
|---|---|---|
| 결과 이해 비율 | 카드 A·D 이해 질문 정답 / 응답 수 | 80% 이상 |
| 처음 보는 사례 대응 | 카드 E에서 가족 확인·공식 번호·직접 확인을 고른 비율 | 기록 |
| 위험 뒤 가족 연락 | 카드 A에서 [가족에게 물어보기]·가족 전화를 고른 비율 | 기록 |

목표에 못 미쳐도 그대로 보고한다. 인원이 적으면 비율과 함께 실제 숫자(예: 17/21)를 쓴다. 피해 감소 효과는 주장하지 않는다.

## 10. 철회와 삭제

- 해외 AI: 카카오는 ‘AI 끄기’, 웹은 [내 설정].
- 가족 연결·계정 삭제: 운영자에게 말하면 그 자리에서 또는 지체 없이 삭제한다(문의: 처리방침 11장).
- 종료: 서버를 멈춘 뒤 [종료 계획](shutdown-plan.md)대로 계정·동의 기록·카카오 동의 기록·확인 기록·백업을 파기한다.

## 11. 중단 조건

아래가 생기면 그 자리에서 멈추고 원인을 고친 뒤 다시 시작한다.

- 참여자가 실제 받은 문자나 개인정보를 넣은 경우: 멈추고, 해당 판정 기록이 있으면 삭제한다(원문은 저장되지 않음).
- 동의하지 않은 사용자의 문장이 AI로 간 것으로 보이는 경우.
- 결과 화면에 ‘안전’처럼 읽히는 문구가 나온 경우.
- 서버 장애가 30분 넘게 이어지는 경우(그날은 운영자 휴대폰 시연과 인터뷰로 대신하고 따로 표시).
- 사무국이 서버·AI 중계 종료를 알린 경우: 남은 일정은 역할극으로 바꾸고 종료 안내([문안](notice-service-period.md) 3장)를 바로 낸다.

## 12. 데이터 흐름 요약

부모님 → (카카오 채널 또는 웹) → 가족방패 서버(국내 VM): 규칙 판정, 가리기 → **동의한 경우에만** 실험실 중계 서버 → Alrouter → Google·Anthropic(미국 등) → 설명 문장 검증 → 결과. 자세한 표는 [처리방침](https://familyshield.kr/privacy) 5장과 [제3자 정보 처리 검토서](legitimate-interest-assessment.md).
