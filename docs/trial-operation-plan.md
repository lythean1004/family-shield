# 시험 운영 계획 (운영 승인 서류 ④) — 초안

작성일: 2026-11-28 · 상태: **초안. 운영자 확인 전, 전문가 검토 전.** 준비 계획 [6단계 ④](compliance-plan-2026-11.md), D43(합성 문자 시나리오), D59(카카오 해외 AI 동의), D60(12월 말까지 운영).
기준 배포: 스킬 `db5d709`, 웹 `74f1c04`(동의 문구 v5 `demo-2026-11-28-v5`, 카카오 동의 `kakao-2026-11-28-v1`, 처리방침·약관 `legal-2026-11-28-v1`).

## 1. 목적과 범위

- 목적: 부모님 세대가 가족방패의 결과를 이해하고, 의심 문자를 받았을 때 가족 확인이나 공식 번호를 고르는지 본다(PRD 15-2 사용성 지표).
- 하지 않는 것: 판별 정확도를 실제 문자로 재는 것, 피해 감소 효과를 주장하는 것.
- **실제 받은 문자는 쓰지 않는다.** 참여자는 운영자가 준비한 합성(가짜) 문자만 쓴다(D43). 실제 문자 처리는 서류 ①~④를 갖추고 전문가 확인을 받은 뒤 따로 정한다.

- 참여는 자유이며 언제든 그만둘 수 있다. 그만둬도 불이익이 없다.

## 4. 합성 문자 시나리오

참여자에게 주는 문자는 운영자가 만든 가짜 문자다. 실제 기관·사람의 번호와 주소는 쓰지 않고, 링크는 넣지 않거나 `example` 같은 가짜 주소만 쓴다. 문자 원문은 평가 세트와 섞지 않으며 저장소에 넣지 않는다(카드 본문은 `private/`).

| 카드 | 유형 | 보려는 것 |
|---|---|---|
| A | 가족 사칭(폰 고장·새 번호·송금 요청), PRD SC1 | 위험 결과 이해, [가족에게 물어보기] 선택 |
| B | 기관 사칭 + 문자 속 번호로 전화 유도, SC2 | 문자 속 번호 대신 [공식 번호 보기] 선택 |
| C | 이미 눌렀어요 상황, SC3 | [이미 눌렀거나 보냈어요] 찾기 |
| D | 신호가 약한 문자, SC4 | ‘확인 필요’가 안전이 아니라는 이해 |
| E | 처음 보는 유형(사전 설명 없이) | 스스로 가족 확인·공식 번호를 고르는지 |

## 5. 직접 설명 대본 (운영자가 읽음, 약 3분)

> 안녕하세요. 저는 가족방패를 만든 ○○○입니다. 가족방패는 의심 문자를 받았을 때 혼자 판단하지 않도록 돕는 **시험 서비스**예요. 2026년 12월 말까지 운영할 예정이고, 멈추는 날은 미리 알려 드려요.
>
> 오늘은 제가 드리는 **가짜 문자**로만 써 주세요. 실제로 받은 문자, 이름, 전화번호, 계좌번호는 넣지 말아 주세요.
>
> 카카오 채널은 사업자 인증을 하지 않은 일반 채널이라 ‘사업자 정보 미확인’이라고 보일 수 있어요. 제가 운영하는 채널이 맞습니다.
>
> 문자를 붙여 넣으면 먼저 정해진 규칙으로 확인해요. 원하시면 [AI 분석 안내]에서 동의할 수 있는데, 동의하시면 번호·계좌를 가린 문장이 **미국 등 해외 AI 회사**로 가요. 동의하지 않아도 문자 확인은 돼요. 그만두고 싶으면 언제든 ‘AI 끄기’라고 보내시면 돼요.
>
> 결과는 참고용이에요. 정상 문자를 위험으로 보거나 위험한 문자를 놓칠 수 있어요. 확실하지 않으면 문자 속 번호 말고, 직접 찾은 공식 번호로 확인하세요.
>
> 오늘 하신 내용은 문자 원문 없이 몇 번 눌렀는지, 어떤 버튼을 골랐는지만 제가 종이에 적어요. 이름이나 연락처는 적지 않아요. 중간에 그만두셔도 괜찮아요. 궁금한 점 있으세요?

- 설명 후 “AI 분석에 동의하면 문장이 어디로 가나요?”를 말로 물어 이해를 확인한다(웹 이해 확인과 같은 질문).
- 동의 여부는 참여자가 직접 누른다. 운영자나 보호자가 대신 누르지 않는다.

## 6. 기록하는 것과 하지 않는 것

| 기록함(종이 또는 익명 표) | 기록하지 않음 |
|---|---|
| 참여 번호(P01…), 연령대(60대/70대/80대), 카드별로 고른 버튼, 도움 없이 끝냈는지, 걸린 시간(분), 결과 이해 질문 정답 여부, 동의 내용을 자기 말로 설명했는지(예/아니오), 불편했던 화면 | 이름, 전화번호, 카카오 계정, 문자 원문, 대화 녹음, 얼굴 사진 |

- 익명 표는 `private/`에 두고 저장소에 넣지 않는다. 결과보고서에는 합계만 쓴다.
- 서버 쪽은 기존 설계대로: 원문 미저장, 판정 기록 24시간, 카카오 동의는 해시값만(D59).

## 7. 측정 지표 (PRD 15-2)

- 결과를 이해한 비율(목표 80% 이상) — 카드 A·D 뒤 “이 결과는 무슨 뜻인가요?” 질문
- 처음 보는 사례(카드 E)에서 가족 확인이나 공식 번호를 고른 비율
- 위험 결과 뒤 가족에게 연락(가족에게 물어보기)한 비율
- SC1~SC4를 도움 없이 끝낸 비율, 설정 완료율과 그만둔 화면, 설정 시간
- 해외 AI 동의 비율과 이해 확인 정답률(참고)

목표에 못 미쳐도 결과를 그대로 보고한다.

## 8. 철회와 삭제

- 해외 AI: 카카오는 ‘AI 끄기’, 웹은 [내 설정].
- 가족 연결·계정 삭제: 운영자에게 말하면 그 자리에서 또는 지체 없이 삭제한다.
- 종료: 서버를 멈춘 뒤 [종료 계획](shutdown-plan.md)대로 계정·동의 기록·카카오 동의 기록·확인 기록·백업을 파기한다.

## 9. 중단 조건

아래가 생기면 시험을 멈추고 원인을 고친 뒤 다시 시작한다.

- 참여자가 실제 받은 문자나 개인정보를 넣은 경우: 그 자리에서 멈추고, 해당 판정 기록이 있으면 삭제한다(원문은 저장되지 않음).
- 동의하지 않은 사용자의 문장이 AI로 간 것으로 보이는 경우.
- 결과 화면에 ‘안전’처럼 읽히는 문구가 나온 경우.
- 서버 장애가 30분 넘게 이어지는 경우.

## 10. 데이터 흐름 요약

부모님 → (카카오 채널 또는 웹) → 가족방패 서버(국내 VM): 규칙 판정, 가리기 → **동의한 경우에만** 실험실 중계 서버 → Alrouter → Google·Anthropic(미국 등) → 설명 문장 검증 → 결과. 자세한 표는 [처리방침](../web/src/data/legal.js) 5장과 [제3자 정보 처리 검토서](legitimate-interest-assessment.md).
