## 고칠 것 (우선순위)

1. **기관 사칭 코드 신호 추가.** "검찰·경찰·금감원·법원·수사관·사건번호·계좌 동결" 같은 키워드를 코드로 잡아 AI가 놓치거나 시간 초과여도 신호가 남게 한다(판정은 올라가기만 하므로 합집합 원칙과 맞음). 놓침의 대부분을 직접 줄인다.
2. **돈·개인정보 키워드 사전 확장.** 놓친 표현을 평가셋에서 뽑아 사전에 넣는다. 단, 평가용 문장을 그대로 넣으면 과적합이므로 **표현 유형**으로 넣고, 확인은 개발용 20건 + 새로 쓴 문장으로 한다(PRD 15-1 분리 원칙).
3. **시간 초과 줄이기.** 3초 제한에서 16.5%. 카카오 5초 안에서 AI 예산을 3.5초로 늘리는 것과, 프롬프트를 줄이는 것을 비교한다.
4. 고친 뒤 같은 조건으로 다시 측정해 전후를 보고한다(중간과제 자료).
