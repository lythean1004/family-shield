# 프로젝트 정의

상태: 선정 (2026 모두의 AI 실험실 예선 통과, 접수번호 AI-2026-000053)

> 이 문서는 범위·금지사항의 요약이다. **범위의 기준은 제출 신청서(docs/application.md)**이고, 기능 요구사항·판정 규칙·데이터·일정의 상세 기준은 docs/prd.md(v0.4)다. 신청서와 다르게 정한 부분은 PRD 6장에 이유가 있다. 바꿀 일이 생기면 먼저 묻는다.

## 선정 과제
가족방패: 부모님이 받은 의심 메시지를 AI가 쉬운 말로 짚어 주고 지금 할 행동을 안내하며, 위험할 땐 가족에게 바로 알리는 사기 예방 웹서비스.

## 대상 사용자
- 문자·메신저로 의심 메시지를 받은 부모님(어르신)
- 부모님이 동의해 연결한 가족
- 검증: 테스트 가족 3곳(장인어른 댁 포함, 1곳 참여 의사 확인) 실사용 → 부모님 세대 20~30명. 어르신 대상 테스트는 동의서 절차를 마련한 뒤

## 범위 (MVP에 포함)
1. 메시지 입력: 텍스트 붙여넣기, 캡처 이미지(휴대폰 안에서 글자 인식, 이미지는 서버로 보내지 않음)
2. 위험 신호 추출 (기관·택배·가족 사칭, 링크·단축 URL·앱 설치 요구, 송금·개인정보 요구, 재촉 등)
3. 링크 확인: 평판 조회 API에 도메인만 질의 (링크 접속·단축 URL 펼치기는 하지 않음)
4. 규칙 코드가 정하는 위험 단계: 위험 / 주의 / 확인 필요 (신청서의 ‘특이점 없음’은 ‘확인 필요’로 표기)
5. 쉬운 말과 음성 읽어주기로 지금 할 일 안내 (연락처·절차는 근거 카드에서만)
6. 가족 확인과 알림: 사칭당한 가족에게 확인 요청, ‘위험’이면 동의한 가족에게 알림(위험 단계와 요약만), 가족용 화면
7. ‘이미 당했어요’ 모드, 우리 집 공식 번호 카드, 가족 암호 안내
8. 결과의 의미와 한계 표시, 오판 신고(별도 동의 시에만 비식별 사례를 개선에 사용)
9. 평가 세트 약 200건으로 놓침률(목표 5% 이하)·오경보율 측정
10. 사용성 검증: 결과 이해 비율(목표 80% 이상), 위험 알림 후 가족 연락 비율, 처음 보는 사례에서 가족 확인이나 공식 번호를 고른 비율
- 결과물 형태: 부모님이 실제로 써 볼 수 있는 웹 프로토타입(목표 구현단계는 프로토타입)
- 공개 데모는 고정 콘텐츠로 제공하고, AI를 호출하는 시연·테스트는 참여 코드와 횟수 제한 뒤에만 연다.

## 후속 (MVP 범위 밖, 일정 여유가 있을 때만)
- 오늘의 퀴즈(PRD F7): 손주가 만든 퀴즈를 앱 안에서 보내 판별·가족 확인 흐름을 미리 연습한다. 연습은 실제 알림과 평가 지표에서 제외한다.
- 카카오톡 채널 챗봇·알림톡: 멘토링에서 요건을 확인한 뒤 검토한다.
- 12/11 이후 로드맵(PRD 20장): 무료 공개 배포 → 오늘의 퀴즈·송금 전 가족 확인 → 복지관·경로당 교육 모드(함께 제출했다가 미선정된 ‘멈춤연습’의 훈련 흐름 활용)·다국어.

## 범위 밖 / 금지사항
- **‘안전’ 판정을 내지 않는다.** 위험 신호가 없어도 “확인 필요”로 두고 공식 경로 확인을 안내한다.
- AI(언어 모델)가 위험 단계나 가족 알림 여부를 정하지 않는다. 규칙 코드가 정한다.
- 메시지 원문을 저장하지 않고, 가족에게 보내지 않는다. 캡처 이미지는 기기 안에서 글자를 인식하며, 인식에 실패했을 때만 부모님의 즉시 동의를 받아 AI로 보낸다(저장 안 함, 법률 검토 후 구현).
- 가족방패는 먼저 링크를 보내지 않는다. 부모님이 채널·앱에서 직접 물었을 때의 답변 버튼만 허용한다.
- 개인정보 동의 항목·문구는 법률 검토를 받은 뒤 확정하고, 그 전에는 실제 사용자 데이터로 운영하지 않는다.
- 메시지 속 링크를 열거나 접속하지 않는다. 단축 URL을 펼치지 않는다. 평판 조회에는 도메인만 보낸다.
- 금융거래 연동, 통화 감청, 실제 송금·신고 대행은 하지 않는다.
- 실제 피해 감소 효과를 주장하지 않는다.
- 결정 전 구현 금지(검토 중): 최종 언어 모델(평가 후 선정), 캡처 글자 인식 라이브러리, URL 평판 조회 API, 카카오톡 채널. docs/decisions.md에 결정이 기록된 뒤 구현한다.

## 용어
| 용어 | 뜻 |
|---|---|
| 위험 신호 | 메시지에서 찾은 사기 의심 특징 (예: 기관 사칭, 링크 클릭 요구) |
| 위험 단계 | 규칙 코드가 위험 신호로 정하는 3단계: 위험 / 주의 / 확인 필요 |
| 근거 카드 | 공식 예방 안내를 정리한 카드. id, 출처 URL, 게시일, 확인일, 적용 범위, 이용조건 확인 여부 |
| 가족 알림 | 위험 단계일 때 동의한 가족에게 보내는 알림. 원문 없이 단계와 요약만 |
| 가족용 화면 | 보호자가 최근 확인 요청·알림과 번호 카드·가족 약속을 보는 화면(신청서의 ‘가족용 대시보드’) |
| 놓침률 | 평가 세트의 위험 메시지 중 ‘위험’으로 잡지 못한 비율 |
| 오경보율 | 평가 세트의 정상 메시지 중 ‘위험’으로 잘못 본 비율 |

## 결과 화면의 의미·한계 안내 문구
> 이 결과는 참고용입니다. 정상 메시지를 위험으로 보거나 위험한 메시지를 놓칠 수 있습니다. 확실하지 않으면 메시지 속 번호나 링크가 아닌, 직접 찾은 공식 번호로 확인하세요.
