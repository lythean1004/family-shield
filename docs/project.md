# 프로젝트 정의

상태: 선정 (2026 모두의 AI 실험실 예선 통과, 접수번호 AI-2026-000053)

> 이 문서는 수행계획서(docs/application.md)를 바탕으로 만든 초안이다. 사람이 검토하기 전까지 아래 범위·금지사항을 기준으로 삼되, 바꿀 일이 생기면 먼저 묻는다.

## 선정 과제
가족방패: 부모님이 받은 의심 메시지를 AI가 쉬운 말로 짚어 주고 지금 할 행동을 안내하며, 위험할 땐 가족에게 바로 알리는 사기 예방 웹서비스.

## 대상 사용자
- 문자·메신저로 의심 메시지를 받은 부모님(어르신)
- 부모님이 동의해 연결한 가족
- 초기 검증: 성인 지인 5~10명 (어르신 대상 검증은 동의 절차와 협력처를 마련한 뒤)

## 범위 (MVP에 포함)
1. 메시지 텍스트 붙여넣기
2. 위험 신호 추출 (기관·택배·가족 사칭, 링크·앱 설치 요구, 송금·개인정보 요구, 재촉 등)
3. 규칙 코드가 정하는 위험 단계: 위험 / 주의 / 확인 필요
4. 쉬운 말 설명과 지금 할 행동 안내 (연락처·절차는 근거 카드에서만)
5. ‘위험’ 단계일 때 동의한 가족에게 알림 (위험 단계와 요약만)
6. 결과의 의미와 한계 표시
7. 위험·정상 메시지를 섞은 평가셋 100건으로 놓침률·오경보율 측정
- 결과물 형태: 웹 프로토타입

## 범위 밖 / 금지사항
- **‘안전’ 판정을 내지 않는다.** 위험 신호가 없어도 “확인 필요”로 두고 공식 경로 확인을 안내한다.
- AI(언어 모델)가 위험 단계나 가족 알림 여부를 정하지 않는다. 규칙 코드가 정한다.
- 메시지 원문을 저장하지 않고, 가족에게 보내지 않는다.
- 메시지 속 링크를 열거나 접속해 검사하지 않는다.
- 금융거래 연동, 통화 감청, 실제 송금·신고 대행은 하지 않는다.
- 실제 피해 감소 효과를 주장하지 않는다.
- 결정 전 구현 금지(검토 중): 사용할 언어 모델, 캡처 이미지 인식, 알림 채널(문자·메신저 연동). docs/decisions.md에 결정이 기록된 뒤 구현한다.

## 용어
| 용어 | 뜻 |
|---|---|
| 위험 신호 | 메시지에서 찾은 사기 의심 특징 (예: 기관 사칭, 링크 클릭 요구) |
| 위험 단계 | 규칙 코드가 위험 신호로 정하는 3단계: 위험 / 주의 / 확인 필요 |
| 근거 카드 | 공식 예방 안내를 정리한 카드. id, 출처 URL, 게시일, 확인일, 적용 범위, 이용조건 확인 여부 |
| 가족 알림 | 위험 단계일 때 동의한 가족에게 보내는 알림. 원문 없이 단계와 요약만 |
| 놓침률 | 평가셋의 위험 메시지 중 ‘위험’으로 잡지 못한 비율 |
| 오경보율 | 평가셋의 정상 메시지 중 ‘위험’으로 잘못 본 비율 |

## 결과 화면의 의미·한계 안내 문구
> 이 결과는 참고용입니다. 정상 메시지를 위험으로 보거나 위험한 메시지를 놓칠 수 있습니다. 확실하지 않으면 메시지 속 번호나 링크가 아닌, 직접 찾은 공식 번호로 확인하세요.
