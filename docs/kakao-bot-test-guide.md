# 카카오 일반 채널 + 챗봇 시험 가이드

> 목적: **사업자등록 없이 만든 일반 채널에서 챗봇을 연결·배포해 카카오톡으로 대화할 수 있는지** 직접 확인한다. 입구 결정(11/2) 전에 끝낸다.
> 소요: 파트 A 1~2시간(코드 없음), 파트 B 30분~1시간(테스트용 스킬 서버 필요).
> 근거: 카카오비즈니스 가이드(kakaobusiness.gitbook.io) 「채널 만들기」「챗봇 관리자센터 준비하기」「튜토리얼 1단계」「봇 설정」「배포」「스킬 만들기」「봇테스트」, 2026-10-21 확인. 화면 이름·위치는 바뀌었을 수 있으니, 다르면 비슷한 메뉴를 찾고 결과표에 적어 둔다.

## 시작 전에
- **PC 브라우저**(크롬)로 진행한다. 카카오톡이 설치된 **휴대폰**도 옆에 둔다(인증·최종 대화 시험용).
- 본인 카카오 계정으로 진행한다. 지인 사업자 정보는 이번 시험에서 쓰지 않는다.
- 시험 중 채팅창에는 **가짜 예시 문장만** 넣는다(실제 받은 문자·번호·이름 금지).
- 각 단계가 끝나면 맨 아래 **결과표**에 ✅/❌와 화면 문구를 적는다. 막히면 그 화면을 캡처해 두면 된다.

## 파트 A. 채널과 봇 만들기 (코드 없음)

### A1. 카카오비즈니스 가입
1. `business.kakao.com` 접속 → 카카오 계정으로 로그인.
2. 카카오비즈니스 통합 회원 전환(약관 동의 → 이름·전화번호 입력 → 완료).
   - 이름은 실명 권장(관리자끼리 구분용, 사용자에게는 안 보임).
   - 같은 전화번호 인증은 **하루 5회까지**라서 실수로 여러 번 누르지 않는다.

### A2. 일반 채널 2개 만들기 (운영용·개발용)
> 챗봇은 “운영 채널”과 “개발 채널”을 따로 연결한다. 배포 실패 점검 항목에 “둘 다 연결되어 있는지”가 있으므로 **처음부터 2개를 만든다**.

1. 카카오비즈니스 파트너센터에서 **[+ 새 비즈니스 만들기]**.
2. 비즈니스 유형 선택(가장 가까운 것, 예: 서비스/기타).
3. 사업자 등록번호 입력 화면에서 **“아니오, 나중에 할게요.”** 선택 → 이것이 **일반 채널**이다.
4. 채널 정보 입력
   - 채널 이름: `가족방패 시험` (두 번째는 `가족방패 개발`)
   - 프로필 사진: 아무 단색 이미지(640×640 권장)
   - 검색용 아이디: 기억하기 쉬운 것
   - 카테고리: 가장 가까운 것
   - **성인 인증 채널은 켜지 않는다**(한 번 켜면 되돌릴 수 없음).
5. 만든 뒤 채널 대시보드에서 확인할 것
   - **‘사업자 정보가 확인되지 않은 채널’ 주의 문구**가 어디에 어떻게 보이는지 → 휴대폰 카카오톡에서 채널을 열어 **캡처**(결과표 A2-경고).
   - **채널 공개**는 켜고, **검색 허용**은 끈다(시험 중 남이 찾지 못하게).
6. 같은 방법으로 두 번째 채널(`가족방패 개발`)을 만든다.

### A3. 채널 채팅 설정
1. 운영 채널 관리 화면에서 **1:1 채팅(채팅 사용)** 을 켠다.
2. 채널 자체의 **자동응답/채팅방 메뉴**가 켜져 있으면 끈다(챗봇 연결 조건).
3. 개발 채널도 똑같이 한다.

### A4. 챗봇 관리자센터 가입과 봇 만들기
1. `chatbot.kakao.com` 접속 → 같은 카카오 계정으로 로그인 → 챗봇 관리자센터 회원가입.
2. 오른쪽 위 **[봇 만들기] → 카카오톡 챗봇** 선택(‘채팅으로 FAQ 챗봇 쉽게 만들기’가 아님).
3. 봇 이름 `가족방패 시험봇` → 확인. 제작 화면으로 이동한다.

### A5. 응답 블록 2개 만들기
1. **웰컴 블록**: 왼쪽 메뉴 웰컴 블록 → 오른쪽 위 ‘미사용’을 **사용 중**으로 → 텍스트형 응답:
   `가족방패 시험 중입니다. 받은 문자를 붙여 넣어 보세요.`
   - 광고성 문구는 넣지 않는다(웰컴 메시지는 야간에도 나갈 수 있어 과태료 대상이 될 수 있음).
2. **폴백 블록**(봇이 못 알아들었을 때 나오는 블록) → 텍스트형 응답:
   `시험 응답: 메시지를 받았어요. (아직 판별 기능은 없습니다)`
   - 우리 서비스는 사용자가 아무 문장이나 붙여 넣으므로, **실제로는 이 폴백 블록이 입구 역할**을 한다.
3. 저장.

### A6. 웹에서 봇 테스트
1. 오른쪽 위 **봇 테스트**(단축키 Ctrl+E).
2. `안녕`, `택배 주소 확인 바랍니다 (예시)` 등을 입력 → 폴백 응답이 나오는지 확인.

### A7. 채널 연결 ★핵심
1. 챗봇 관리자센터 왼쪽 **설정** → 기본 정보.
2. **운영 채널 연결**에서 `가족방패 시험` 선택.
3. **개발 채널 연결**에서 `가족방패 개발` 선택.
4. **목록에 일반 채널이 보이는지, 선택·저장이 되는지, 오류 문구가 뜨는지** 그대로 기록(결과표 A7).
   - ‘앱키 설정’, ‘디벨로퍼스 앱 연결’은 **하지 않는다**(개인정보를 받는 기능용이고 비즈니스 인증이 필요하다).

### A8. 배포 ★핵심
1. 왼쪽 **배포** → **전체 배포** 선택 → 배포 내용에 `일반 채널 시험 v1` → 배포.
2. 배포는 중간에 멈출 수 없고 최대 30분 걸릴 수 있다.
3. 성공하면 봇 상태가 ‘준비’ → **‘실행’**으로 바뀐다. 실패하면 **배포 히스토리의 실패 사유**를 그대로 적는다(결과표 A8).
   - 공식 문서의 실패 점검 항목: ① 운영·개발 채널이 같은 비즈앱에 연결되어 있는지 ② 설정에서 두 채널이 모두 연결되어 있는지. **①이 이유로 실패하면 ‘일반 채널 불가’의 강한 증거**다.

### A9. 휴대폰 카카오톡에서 실제 대화
1. 휴대폰 카카오톡에서 `가족방패 시험` 채널을 열고(관리자는 ‘관리중 채널’에서 보임) **채널 추가 → 채팅**.
2. 웰컴 메시지가 오는지, 아무 문장을 보내면 폴백 응답이 오는지 확인.
3. 이때 화면 위나 채널 홈에 보이는 **경고 문구를 캡처**(부모님이 보게 될 화면).
4. 가능하면 가족 1명(관리자 아님)에게 채널을 추가해 보게 하고 같은 화면이 보이는지 확인.

> **여기까지 성공하면 “일반 채널로 챗봇 운영 가능”이 확인된다.** 파트 B는 우리 서버가 답을 만드는 구조(스킬)도 되는지 보는 단계다.

## 파트 B. 스킬 서버 연결 (우리 서버가 답하기)

> 스킬 서버는 **공개 인터넷 주소(https)** 여야 하고(내 PC의 localhost는 안 됨), **5초 안에** 답해야 한다(시간 고정, 조정 불가).
> **이 단계 전에 Claude에게 “시험용 스킬 서버 만들어 줘”라고 요청한다.** 받은 글자를 저장·기록하지 않고 “받은 글자 수”와 고정 문장만 돌려주는 최소 서버를 Vercel 무료 계정에 올리는 방식으로 준비한다(앱 코드가 아닌 일회성 시험용).

### B1. 스킬 등록
1. 챗봇 관리자센터 왼쪽 **스킬** → **생성**.
2. 스킬명 `echo-test`, URL에 시험용 서버 주소(예: `https://…/api/kakao-skill`) 입력.
3. 같은 화면의 **스킬 테스트** → **스킬 서버로 전송** → ‘응답 미리보기’에 시험 문장이 나오는지 확인. 실패하면 ‘응답 결과 로그’를 그대로 적는다.

### B2. 폴백 블록에 스킬 연결
1. 폴백 블록 → 파라미터 설정 → **스킬 선택**에서 `echo-test`.
2. 봇 응답을 **스킬데이터 사용**으로 바꾼다(스킬이 만든 답을 그대로 보여주기).
3. **폴백 블록에 스킬 연결이 되는지 자체가 확인 항목**이다(우리 입구 구조의 전제). 안 되면 일반 블록에 넣고 결과표에 적는다.
4. 저장 → 봇 테스트(Ctrl+E)에서 확인 → 상세 정보의 **더보기**로 요청/응답 JSON이 보이는지 확인.

### B3. 다시 배포하고 휴대폰 확인
1. **전체 배포**(스킬은 블록과 함께 배포해야 반영됨).
2. 휴대폰 채팅방에서 예시 문장을 보내 `받은 글자 수: N` 같은 답이 오는지, 몇 초 걸리는지 확인.

## 결과에 따른 다음 행동
- **A8까지 성공**: 개발·내부 시험은 일반 채널로 진행. 테스트 가족 실사용 전에 경고 문구 제거(비즈니스 채널 전환)를 따로 준비한다.
- **A7·A8에서 비즈앱/비즈니스 인증 때문에 실패**: 일반 채널 불가로 확정 → ① 개인 자격 비즈니스 심사 조건 확인(카카오 고객센터 ‘업종별 요건과 자격 서류’ 안내) ② 마지막 수단으로 지인 사업자 위임 ③ 공유·단축어 입구를 주 경로로.
- **B2가 안 됨(폴백에 스킬 불가)**: 일반 블록 + 발화 패턴으로 받는 구조를 다시 설계해야 하므로 Claude와 상의.
- 시험이 끝나면 채널은 **검색 비허용 상태로 유지**하거나 삭제한다. 봇 삭제는 신청 7일 뒤 완료된다.
