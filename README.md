# 가족방패 (Family Shield)

부모님이 의심 문자를 받은 그 순간, 혼자 판단하지 않도록 돕는 **가족 확인 서비스**입니다. 메시지를 붙여 넣으면 AI가 위험 신호를 쉬운 말로 짚어 주고, 가족을 사칭한 문자라면 사칭당한 가족 본인에게 바로 “진짜 보냈는지” 확인을 요청해 그 답이 부모님 화면에 돌아옵니다.

2026 모두의 AI 실험실 프로젝트입니다(접수번호 AI-2026-000053, 마감 2026-12-18).

> **현재 단계: 기획 완료, 구현 전.** 상세 PRD v0.3과 개발 준비 점검을 마쳤고, 1주차 사전 구성을 시작합니다.

## 왜 만드나
피싱 피해는 전화를 받은 뒤 문자로 넘어가는 순간 커지는 경우가 많습니다. 그 순간 부모님은 혼자 판단해야 하고, 가족이나 믿을 수 있는 공식 번호에 안전하게 바로 닿을 방법이 없습니다.

## 하는 일
1. **판별**: 문자를 붙여 넣고 전화를 받았는지 답하면, 위험 신호를 찾아 **위험 / 주의 / 확인 필요** 3단계로 보여 줍니다.
2. **가족 확인**: 가족 사칭이면 사칭당한 가족 본인에게 확인 요청을 보냅니다. 가족이 탭 한 번으로 “보낸 적 없어요”라고 답하면 부모님 화면에 바로 나타납니다.
3. **행동 안내와 사후 대응**: 통화 중이면 끊기부터, 이미 링크를 눌렀거나 앱을 깔았다면 다른 전화 사용·경찰서 방문 순서로 안내합니다.
4. **우리 집 공식 번호 카드**: 출처가 확인된 공식 번호를 미리 등록해 오프라인에서도 봅니다.

## 원칙
- **‘안전’ 판정은 내지 않습니다.** 결과는 참고용이며 판정은 올라가기만 합니다.
- **판정은 규칙 코드가 합니다.** AI는 신호를 뽑고 설명을 쓰기만 합니다.
- **가족방패는 링크를 보내지 않습니다.** 초대는 QR·숫자 코드로 합니다.
- **원문을 남기지 않습니다.** AI로 보내기 전에 번호·계좌 등을 가리고, 원문은 저장하지 않으며, 판별 기록은 24시간 뒤 삭제합니다.
- **근거가 있는 번호만 씁니다.** 연락처와 절차는 출처·확인일이 있는 근거 카드에서만 가져옵니다.
- **부모님이 주인입니다.** 동의는 부모님 휴대폰에서 직접 하고 언제든 끌 수 있습니다.

|---|---|

| 디자인 | Figma |
| 구현 보조 | Claude Code |
