# 가족방패 (Family Shield)

부모님이 받은 의심 메시지를 AI가 쉬운 말로 짚어 주고 지금 할 행동을 안내하며, 위험할 땐 가족에게 바로 알리는 사기 예방 웹서비스입니다. 2026 모두의 AI 실험실 프로젝트입니다.

> 현재 단계: 아이디어 구체화 (구현 전)

## 하는 일
1. 부모님이 받은 문자·메신저 메시지를 붙여 넣으면 위험 신호를 찾아 보여 줍니다.
2. 위험 단계(위험 / 주의 / 확인 필요)와 이유를 큰 글씨, 짧은 문장으로 알려 줍니다.
3. 링크 누르지 않기, 송금 멈추기, 공식 번호로 확인하기 등 지금 할 행동을 안내합니다.
4. ‘위험’ 단계이면 미리 동의해 연결한 가족에게 알립니다. 메시지 원문은 보내지 않습니다.

## 원칙
- ‘안전’ 판정은 내지 않습니다. 판별 결과는 참고용입니다.
- 위험 단계는 AI가 아니라 미리 정한 규칙이 결정합니다.
- 연락처와 절차는 공식 예방 안내를 정리한 근거 카드에서만 가져옵니다.
- 메시지 원문은 저장하지 않고, 전화번호·계좌번호 등은 AI로 보내기 전에 가립니다.
