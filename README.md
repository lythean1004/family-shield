# 가족방패 (Family Shield)

부모님이 의심 문자를 받은 그 순간, 혼자 판단하지 않도록 돕는 **가족 확인 서비스**입니다. 메시지를 붙여 넣으면 AI가 위험 신호를 쉬운 말로 짚어 주고, 가족을 사칭한 문자라면 사칭당한 가족 본인에게 바로 “진짜 보냈는지” 확인을 요청해 그 답이 부모님 화면에 돌아옵니다.

2026 모두의 AI 실험실 프로젝트입니다(접수번호 AI-2026-000053, 중간과제 2026-11-16, 최종 마감 2026-12-11).

> **현재 단계: 시연용 VM 통합 배포 완료.** 쿠키 로그인·초대·동의, 가족 확인 왕복, DB 결과 토큰, 웹 푸시를 구현하고 HTTPS 왕복·아이폰 알림 수신과 클릭을 확인했습니다. 정확도 목표는 아직 미달입니다. [인계 문서](docs/handoff.md)에서 세부 상태를 확인하세요. 법률 검토 전에는 가상 문자만 사용합니다(D26).

## 왜 만드나
피싱 피해는 전화를 받은 뒤 문자로 넘어가는 순간 커지는 경우가 많습니다. 그 순간 부모님은 혼자 판단해야 하고, 가족이나 믿을 수 있는 공식 번호에 안전하게 바로 닿을 방법이 없습니다.

## 출발점
장인어른의 피싱 피해 이야기를 들은 아이가 엔트리로 사기방지 메시지 앱을 만들었고, 그 아이디어를 AI 서비스로 완성하는 프로젝트입니다. 3대가 함께 만드는 가족 안전망을 지향합니다.

## 하는 일
1. **판별**: 문자를 붙여 넣고 전화를 받았는지 답하면, 위험 신호를 찾아 **위험 / 주의 / 확인 필요** 3단계로 보여 줍니다. 캡처 글자 인식은 후속 작업입니다.
2. **가족 확인**: 부모님이 직접 요청하면 연결한 보호자가 가족용 화면에서 확인하고 답합니다. “보낸 적 없어요”라고 답하면 부모님 판정이 위험으로 올라갑니다. 이번 시연에서는 자동 위험 알림을 보내지 않습니다(D39).
3. **쉬운 말·음성 안내**: 지금 할 일을 3가지 이내로, 큰 글씨와 음성 읽어주기로 안내합니다.
4. **‘이미 당했어요’ 모드**: 이미 링크를 눌렀거나 앱을 깔았다면 다른 전화 사용·경찰서 방문 순서로 안내합니다.
5. **공식 번호 카드와 가족 암호 안내**: 출처가 확인된 공식 번호를 오프라인에서도 보고, 가족 암호는 목소리 통화에서만 정하도록 안내합니다.

## 원칙
- **‘안전’ 판정은 내지 않습니다.** 결과는 참고용이며 판정은 올라가기만 합니다.
- **판정은 규칙 코드가 합니다.** AI는 신호를 뽑고 설명을 쓰기만 합니다.
- **가족방패는 링크를 보내지 않습니다.** 초대는 QR·숫자 코드로 합니다.
- **원문을 남기지 않습니다.** AI로 보내기 전에 번호·계좌 등을 가리고 원문은 저장하지 않습니다. 웹 판별 기록은 동의한 경우 최대 24시간 보관합니다(삭제 작업 최대 10분 지연, 백업 최대 7일). 기록 미동의자는 가족 요청 시 별도 동의를 받습니다.
- **링크에 접속하지 않습니다.** 링크는 평판 조회에 도메인만 묻고, 단축 링크는 펼치지 않습니다.
- **근거가 있는 번호만 씁니다.** 연락처와 절차는 출처·확인일이 있는 근거 카드에서만 가져옵니다.
- **부모님이 주인입니다.** 동의는 부모님 휴대폰에서 직접 하고 언제든 끌 수 있습니다.

## 기술 구성 (D36)
| 구성 | 선택 |
|---|---|
| 앱 | 부모님은 카카오톡 채널 챗봇으로 물어보고, 설정·음성·가족용 화면은 웹(PWA). 설치 없이 사용 |
| 캡처·음성 | 브라우저 내장 음성 읽어주기. 휴대폰 안 글자 인식은 후속 작업 |
| 백엔드 | NCP VM의 PostgreSQL 16 + Node API. 쿠키 세션, 요청마다 RLS 적용. DB 외부 포트 없음 |
| 배포 | 네이버클라우드(NCP) 서버: 웹(PWA)과 카카오 챗봇 스킬 서버(D29) |
| 알림 | 수동 가족 확인 요청의 웹 푸시. 예비 문자는 후속 작업 |
| AI | 카카오 Gemini 3.1 Flash-Lite(3초), 웹 Claude Sonnet 5.5(8초), aitestbed 중계(D30) |
| 디자인 | 코드로 직접 구현, 부모님 본문 30px·고대비(D31·D32) |
| 구현 보조 | Claude Code, Codex |

## 한계
판별은 참고용이며, 정상 문자를 위험하다고 하거나 위험한 문자를 놓칠 수 있습니다. 평가 세트는 공개 사례를 바탕으로 직접 쓴 문자와 동의받아 비식별화한 정상 문자로 만들며, 실제 피해 감소 효과는 주장하지 않습니다.
